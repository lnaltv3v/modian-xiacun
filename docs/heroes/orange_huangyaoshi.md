# 黃藥獅（橙）

> 影射設定文檔｜墨點俠村｜招式皆原創改編名，唔用原著全稱。

## 基本
- **id**：`orange_huangyaoshi`
- **影射名**：黃藥獅
- **原聯想**：黃藥師
- **兵種**：暗器
- **稀有**：橙
- **基礎戰力**：36
- **性格**：奇傲、聰明絕頂、厭世俗禮教；對有才者惜，對偽善者毒。

## 背景（粵語繁中）
東海桃花島主，琴棋書畫毒皆精。俠村請其改進丹房配方，交換條件係：島上琴譜副本一份。

## 外觀特徵（給美術）
- **目標解像**：128×128
- **剪影**：青衫文士、執簫、袖藏石子；儒雅含殺氣。
- **色盤備註**：青綠衫＋桃花粉點（克制）＋簫褐。
- **招牌道具**：玉簫, 青衫, 桃花瓣（特效）, 棋子暗器
- **特效階**：絕學級：音刃波、大招落英暗器雨。

## 技能（2–4）
- **碧海潮生曲影**（`bi_hai_xiao`）：音波範圍傷＋混亂機率。
- **彈指神通意**（`tan_zhi_shen`）：遠程破甲石子。
- **奇門布陣**（`qi_ju`）：地面陷阱區，敵進入減速。
- **傲骨文人**（`ao_gu`）：被動：對「偽君子／門派敵」傷害提升。

## 成長傾向
- **定位**：法術型暗器
- **屬性偏向**：生命 中低／攻擊 高／防禦 中／速度 中高
- **備註**：毒沼相性佳。

## 美術／演出備註
- 稀有度愈高愈華麗、特徵愈鮮明；紅階 256、橙階 128。
- 硬邊墨點、宣紙底、嚴格色盤；禁止寫實／盤外色／柔邊。
- 技能攻擊特效跟稀有度誇張度：橙明顯、紅神話級。
