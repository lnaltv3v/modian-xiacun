# 黃裳（紅）

> 影射設定文檔｜墨點俠村｜招式皆原創改編名，唔用原著全稱。

## 基本
- **id**：`red_huangshang`
- **影射名**：黃裳
- **原聯想**：黃裳
- **別名候選**：黃常
- **兵種**：暗器
- **稀有**：紅
- **基礎戰力**：47
- **性格**：學者脾氣：慢熱、較真、一鑽研就廢寢忘食。對「招式結構」比對勝負更興奮。

## 背景（粵語繁中）
帝都舊吏，因校對經卷悟出攻防循環之理，寫成駭世心法後隱姓埋名。江湖只知「九陰殘卷」來源成謎；俠村以古籍碎片換得其現身——條件係：給一間安靜書房同唔限量墨。

## 外觀特徵（給美術）
- **目標解像**：256×256
- **剪影**：文士長袍、袖藏短弩／鐵蓮；文弱外表對比殺招。
- **色盤備註**：墨褐文袍＋硃砂批註色點＋鐵灰暗器。
- **招牌道具**：書卷, 袖弩, 鐵蓮花, 墨指痕
- **特效階**：神話級：技能帶經文浮現、大招九宮格暗器陣；入場翻書一頁化刃。

## 技能（2–4）
- **殘卷殺機**（`jiu_yin_can`）：閱讀式詠唱後釋放高傷暗器陣；可被打斷。
- **攻防輪轉**（`gong_fang_huan`）：切換攻／防姿態：攻＝傷高；防＝反彈暗器。
- **經文鎖脈**（`jing_wen_suo`）：降低目標全屬性，疊加可封印大招。
- **十部邪功解**（`shi_bu_xie`）：被動：對使用「毒／邪／吸」類技能敵人減傷並反噬。

## 成長傾向
- **定位**：智控與陣法輸出
- **屬性偏向**：生命 中低／攻擊 高／防禦 中／速度 中
- **備註**：需站樁詠唱；搭配控場棍僧。

## 美術／演出備註
- 稀有度愈高愈華麗、特徵愈鮮明；紅階 256、橙階 128。
- 硬邊墨點、宣紙底、嚴格色盤；禁止寫實／盤外色／柔邊。
- 技能攻擊特效跟稀有度誇張度：橙明顯、紅神話級。
