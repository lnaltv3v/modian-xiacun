# 獨孤求拜（紅）

> 影射設定文檔｜墨點俠村｜招式皆原創改編名，唔用原著全稱。

## 基本
- **id**：`red_dugu`
- **影射名**：獨孤求拜
- **原聯想**：獨孤求敗
- **兵種**：劍
- **稀有**：紅
- **基礎戰力**：50
- **性格**：淡泊如水，卻藏好勝之心——一生只求一敗。寡言，對後輩偶有點破，從不收徒名義。

## 背景（粵語繁中）
劍塚隱士，歷青鋒、軟劍、重劍、木劍四境。武林無人能敗，故自號「求拜」。俠村秘境深處曾見其木劍插碑；請出後只問：「爾等可有能令我輸一招之人？」

## 外觀特徵（給美術）
- **目標解像**：256×256
- **剪影**：青袍負木劍、身形清瘦如竹；站姿極鬆，一出手劍勢如山。
- **色盤備註**：青衫＋枯木褐＋劍氣淡白；木劍無鞘。
- **招牌道具**：青袍, 背上木劍, 空石台剪影（入場）, 無華麗飾物
- **特效階**：神話級：大招簡到極致——一劍白線貫屏、餘韻長；入場石碑碎影。

## 技能（2–4）
- **木劍一式**（`mu_jian_yi`）：看似輕挑，實為破防真傷；無視部分防禦。
- **劍冢遺意**（`jian_zhong_yi`）：切換「重／木」心法：重＝高傷慢；木＝快斬連段。
- **求敗之勢**（`qiu_bai_shi`）：血量越低攻擊越高；低於三成時每擊附帶擊暈機率。
- **無招勝有招**（`wu_zhao_sheng`）：被動：對持兵器敵人提升暴擊；自身無兵器加成改為全額。

## 成長傾向
- **定位**：單體斬殺與破防
- **屬性偏向**：生命 中／攻擊 極高／防禦 中／速度 中高
- **備註**：Boss 殺手；群戰略遜暗器／槍。
