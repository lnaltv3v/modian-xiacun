# 一登大師（橙）

> 影射設定文檔｜墨點俠村｜招式皆原創改編名，唔用原著全稱。

## 基本
- **id**：`orange_yideng`
- **影射名**：一登大師
- **原聯想**：一燈大師
- **兵種**：拳腳
- **稀有**：橙
- **基礎戰力**：36
- **性格**：慈悲、沉穩、前朝帝王心性仍在；出手點到即止，除非救眾生。

## 背景（粵語繁中）
南帝出家後隱於石林。俠村醫館缺「一陽真氣」療傷法，故遠迎之。

## 外觀特徵（給美術）
- **目標解像**：128×128
- **剪影**：金紅袈裟、光頭、單指蓄光；慈眉。
- **色盤備註**：袈裟紅金＋指尖暖光。
- **招牌道具**：袈裟, 念珠, 指光, 蒲團影子
- **特效階**：絕學級：指光療傷／殺傷雙形態、大招佛光罩。

## 技能（2–4）
- **一陽指墨光**（`yi_yang_zhi`）：可切治療或傷害形態。
- **六脈餘氣**（`liu_mai_qi`）：遠程氣勁連射（簡化）。
- **慈悲願**（`ci_bei`）：強療瀕死友方（冷卻長）。
- **南帝遺澤**（`nan_di`）：被動：醫館相關回復效果對全隊微增。

## 成長傾向
- **定位**：治療與點穴
- **屬性偏向**：生命 中／攻擊 中高／防禦 中／速度 中
- **備註**：珍稀輔助橙。

## 美術／演出備註
- 稀有度愈高愈華麗、特徵愈鮮明；紅階 256、橙階 128。
- 硬邊墨點、宣紙底、嚴格色盤；禁止寫實／盤外色／柔邊。
- 技能攻擊特效跟稀有度誇張度：橙明顯、紅神話級。
