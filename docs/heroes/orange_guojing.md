# 郭靚（橙）

> 影射設定文檔｜墨點俠村｜招式皆原創改編名，唔用原著全稱。

## 基本
- **id**：`orange_guojing`
- **影射名**：郭靚
- **原聯想**：郭靖
- **兵種**：拳腳
- **稀有**：橙
- **基礎戰力**：38
- **性格**：愚直忠誠、為國為民；反應不快但打實。對承諾死守。

## 背景（粵語繁中）
大漠長大，學成降龍一路拳意後守城無數。俠村請其坐鎮前哨時，佢只問：「啲村民食唔食得飽？」答得飽，就留下。

## 外觀特徵（給美術）
- **目標解像**：128×128
- **剪影**：壯碩、勁裝、雙拳如龍；臉憨厚。
- **色盤備註**：土褐勁裝＋龍氣金黃（特效）＋腰帶銅扣。
- **招牌道具**：寬腰帶, 護腕, 樸素勁裝, 無華飾
- **特效階**：絕學級：降龍氣柱、大招龍形拳影。

## 技能（2–4）
- **降龍十八式（節）**（`xiang_long_shi`）：連續重拳，收尾範圍震地。名用「節」示意原創改編，唔用原著全稱。
- **飛龍在天影**（`fei_long_zai`）：跳躍砸擊，對群獸高效。
- **亢龍有悔意**（`kang_long_you`）：蓄力越久傷越高；可取消為防禦姿。
- **俠義骨**（`xia_yi_gu`）：被動：守護低血隊友時自身減傷。

## 成長傾向
- **定位**：正面群戰與守點
- **屬性偏向**：生命 高／攻擊 高／防禦 高／速度 低
- **備註**：前哨首選橙階。

## 美術／演出備註
- 稀有度愈高愈華麗、特徵愈鮮明；紅階 256、橙階 128。
- 硬邊墨點、宣紙底、嚴格色盤；禁止寫實／盤外色／柔邊。
- 技能攻擊特效跟稀有度誇張度：橙明顯、紅神話級。
