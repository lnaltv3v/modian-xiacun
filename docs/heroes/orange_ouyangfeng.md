# 歐陽峰（橙）

> 影射設定文檔｜墨點俠村｜招式皆原創改編名，唔用原著全稱。

## 基本
- **id**：`orange_ouyangfeng`
- **影射名**：歐陽峰
- **原聯想**：歐陽鋒
- **兵種**：棍
- **稀有**：橙
- **基礎戰力**：37
- **性格**：狠辣、執拗、為達目的不擇手段；顛倒練法後神智時清時亂，戰力反而更怪。

## 背景（粵語繁中）
西域毒傑，白駝山主。俠村以「解毒需知毒」為由請其坐鎮醫館顧問——村民又敬又怕。

## 外觀特徵（給美術）
- **目標解像**：128×128
- **剪影**：白衣披髮、蛇杖、眼白可翻（狂態）；詭異。
- **色盤備註**：白衣＋蛇鱗綠＋毒紫霧（盤內梵紫）。
- **招牌道具**：蛇杖, 白衣, 毒囊, 披髮
- **特效階**：絕學級：毒霧、逆行關節打擊、大招蟾震。

## 技能（2–4）
- **蛤蟆功影**（`ham_gong`）：蓄力彈射衝撞，擊退＋毒。
- **靈蛇杖法**（`she_zhang`）：棍技連打，附帶中毒。
- **逆運經脈**（`ni_yun`）：短時自傷換極高攻擊。
- **西部毒王**（`xi_du`）：被動：毒傷加深；己方醫館效率對其隊伍微升（設定向）。

## 成長傾向
- **定位**：毒控與爆發
- **屬性偏向**：生命 中／攻擊 高／防禦 中／速度 中
- **備註**：毒沼王牌；注意自傷風險。

## 美術／演出備註
- 稀有度愈高愈華麗、特徵愈鮮明；紅階 256、橙階 128。
- 硬邊墨點、宣紙底、嚴格色盤；禁止寫實／盤外色／柔邊。
- 技能攻擊特效跟稀有度誇張度：橙明顯、紅神話級。
