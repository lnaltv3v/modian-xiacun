# 令狐忠（橙）

> 影射設定文檔｜墨點俠村｜招式皆原創改編名，唔用原著全稱。

## 基本
- **id**：`orange_linghuzhong`
- **影射名**：令狐忠
- **原聯想**：令狐沖
- **兵種**：劍
- **稀有**：橙
- **基礎戰力**：35
- **性格**：瀟灑不羈、重義輕名；喝酒比練劍勤——但劍一出仍驚四座。

## 背景（粵語繁中）
華山棄徒出身，得隱世劍法真傳後笑傲江湖。俠村茶寮常客；接委託前要先問有冇好酒。

## 外觀特徵（給美術）
- **目標解像**：128×128
- **剪影**：青衫負劍、衣襟鬆散、笑意；劍勢隨意卻無破綻。
- **色盤備註**：青衫＋酒葫蘆褐＋劍光銀白。
- **招牌道具**：酒葫蘆, 青衫, 長劍, 散髮
- **特效階**：絕學級：劍花連綿、大招無招劍網。

## 技能（2–4）
- **笑傲劍意**（`xiao_ao_jian`）：連斬提升攻速，可閃避一次攻擊。
- **獨孤九式影**（`du_gu_jiu`）：破兵器特效：對持械敵人額外傷害。
- **醉仙步**（`zui_xian`）：位移＋短暫無敵幀。
- **義氣相挺**（`yi_qi`）：被動：鄰近友方暴擊率微升。

## 成長傾向
- **定位**：靈活劍客
- **屬性偏向**：生命 中／攻擊 高／防禦 中低／速度 高
- **備註**：PvE 清場佳；生存靠走位。

## 美術／演出備註
- 稀有度愈高愈華麗、特徵愈鮮明；紅階 256、橙階 128。
- 硬邊墨點、宣紙底、嚴格色盤；禁止寫實／盤外色／柔邊。
- 技能攻擊特效跟稀有度誇張度：橙明顯、紅神話級。
