# 東方唔敗（紅）

> 影射設定文檔｜墨點俠村｜招式皆原創改編名，唔用原著全稱。

## 基本
- **id**：`red_dongfang`
- **影射名**：東方唔敗
- **原聯想**：東方不敗
- **兵種**：暗器
- **稀有**：紅
- **基礎戰力**：52
- **性格**：孤傲、戲謔、極自信；視多數對手為「尚未入眼」。對美與速度近乎偏執，對背叛零容忍。

## 背景（粵語繁中）
曾以一身繡花針技壓倒整代武林，隱於高山繡樓多年。江湖流傳「正面接招者皆敗」——唔係誇張，係統計。被俠村以英雄帖請出山時，只丟下一句：「有趣嘅獵物先值得落針。」

## 外觀特徵（給美術）
- **目標解像**：256×256
- **剪影**：紅衣長髮、單手執繡箍、針雨成扇；剪影極細長、飄帶誇張。
- **色盤備註**：硃紅主色＋墨黑髮＋銀針高光；禁用粉嫩盤外色。
- **招牌道具**：硃紅繡袍, 長髮及腰, 銀繡針簇, 腰間花繡箍
- **特效階**：神話級：針雨全屏斜線、大招時間減速感（幀停短促）、入場紅絲繚繞。

## 技能（2–4）
- **繡花針雨**（`xiu_hua_yu`）：遠程多段傷害，命中疊「刺痕」；滿層爆開額外毒傷。
- **紅絲鎖喉**（`hong_si_suo`）：定身／減速單體，短時間無法接近；對刺客類額外有效。
- **飛花摘葉**（`fei_hua_cai`）：瞬間位移並對路徑敵人造成切割；可取消自身硬直。
- **無敵東風**（`wu_di_dong`）：終極：短暫無敵＋極高攻速針雨，結束後大硬直需隊友掩護。

## 成長傾向
- **定位**：極限輸出與風箏
- **屬性偏向**：生命 低／攻擊 極高／防禦 低／速度 極高
- **備註**：玻璃大炮；前哨需棍／拳腳擋前。

## 美術／演出備註
- 稀有度愈高愈華麗、特徵愈鮮明；紅階 256、橙階 128。
- 硬邊墨點、宣紙底、嚴格色盤；禁止寫實／盤外色／柔邊。
- 技能攻擊特效跟稀有度誇張度：橙明顯、紅神話級。
