# 墨點俠村 · 試玩檢查清單（v0.9.1）

繁中。本機：`tools/play.sh`；Web：`cd export/web && python3 -m http.server 8877` 再開瀏覽器。

## A. 開局／教學
- [ ] 開局有六綠俠、銀／木足夠建客棧
- [ ] 教學三步：興建客棧 → 派遣亂山坡 → 回村收資源（可跳過）
- [ ] 頂欄標題顯示 **v0.9.1**；銀／木／毛皮／鐵各自有圖示＋數字，**唔被裁切**

## B. 村莊建築（自由放置）
- [ ] 「放」可揀未建建築，點空地放置；Esc／右鍵取消
- [ ] 幽靈預覽：綠可放／紅不可（疊建築、出界）
- [ ] 升級成本隨等級上升（客棧 Lv1→Lv3→更高明顯變貴）
- [ ] 客棧／醫館／練功場生效：飽食、療傷、閒置 XP

## C. 出征循環
- [ ] 亂山坡倒數約 **14 秒**；毒沼約 **20 秒**（懸賞榜 Lv.2）
- [ ] 剔選俠客出征 → 短自動戰鬥 → 回村收銀／毛皮（／鐵）
- [ ] 失敗時收益縮水、可能額外受傷
- [ ] 自動再出征（同時最多約 2 隊）可開關
- [ ] 離線／讀檔後到期出征會結算

## D. 俠客列表／稀有
- [ ] 頭像有**稀有色邊**（白→綠→藍→紫→橙→紅）
- [ ] 紫階抽中後顯示 **96×96** 專圖（唔係色塊）；列表縮放正常
- [ ] 橙 128／紅 256 縮到列表尺寸唔爆框
- [ ] 若偶發無圖色塊：清楚顯示**兵種短標＋稀有**

## E. 抽卡／進階系統
- [ ] 英雄帖扣銀；紫池 12 人（韋小保…岳不裙）
- [ ] 橙／紅軟保底有記錄（回報可見 pity）
- [ ] 懸賞目標、兵器鋪自動買裝、貨棧製／自動販毛皮
- [ ] 亂山秘境多波、師門書院被動、前哨／比武台 stub 可撳唔崩

## F. 存檔／穩定性
