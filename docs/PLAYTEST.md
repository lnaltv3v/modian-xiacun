# 墨點俠村 · 試玩檢查清單（v0.16.0）

繁中。本機：`tools/play.sh`；Web：`cd export/web && python3 -m http.server 8877` 再開瀏覽器。

## A. 開局／教學
- [ ] 開局有六綠俠、銀／木足夠建客棧
- [ ] 教學六步：興建客棧 → 派遣 → 回村 → 抽卡／興建 → 秘境選擇 → 前哨／書院（可跳過；舊檔完成唔重播）
- [ ] 頂欄標題顯示 **v0.9.5**；銀／木／毛皮／鐵各自有圖示＋數字，**唔被裁切**

## B. 村莊建築（自由放置）
- [ ] 「放」可揀未建建築，點空地放置；Esc／右鍵取消
- [ ] 幽靈預覽：綠可放／紅不可（疊建築、出界）
- [ ] 升級成本隨等級上升（客棧 Lv1→Lv3→更高明顯變貴）
- [ ] 客棧／醫館／練功場生效：飽食、療傷、閒置 XP

## C. 出征循環
- [ ] 亂山坡倒數約 **14 秒**；毒沼約 **20 秒**（懸賞榜 Lv.2）
- [ ] 剔選俠客出征 → 短自動戰鬥（亂山＝hills／毒沼＝mire 底圖）→ 回村收銀／毛皮（／鐵）；結算文案有拾獲筆記／受傷提示
- [ ] 秘境用 crypt、前哨用 outpost 戰鬥底圖
- [ ] 失敗時收益縮水、可能額外受傷
- [ ] 自動再出征（同時最多約 2 隊）可開關
- [ ] 離線／讀檔後到期出征會結算

## D. 俠客列表／稀有
- [ ] 頭像有**稀有色邊**（白→綠→藍→紫→橙→紅）
- [ ] 紫階抽中後顯示 **96×96** 專圖（唔係色塊）；列表縮放正常
- [ ] 橙 128／紅 256 縮到列表尺寸唔爆框
- [ ] 若偶發無圖色塊：清楚顯示**兵種短標＋稀有**

## E. 抽卡／進階系統
- [ ] 英雄帖扣銀；紫池 12 人（韋小保…岳不裙）
- [ ] 橙／紅軟保底有記錄（回報可見 pity）
- [ ] 懸賞目標、兵器鋪自動買裝、貨棧製／自動販毛皮
- [ ] 亂山秘境多波、師門書院被動、前哨可撳；**比武台**：剔兩俠→自動切磋演出→XP／日限

## F. 存檔／穩定性
- [ ] 存／讀一致（資源、建築位、俠客、pity）
- [ ] Web 版可載入；主循環唔即閃退
- [ ] headless：`godot --headless --path . res://scenes/dev/smoke_v092.tscn` → `SMOKE_V092_OK`
