- [ ] 開局有六綠俠、銀／木足夠建客棧
- [ ] 教學四步：興建客棧 → 派遣亂山坡 → 回村收資源 → 抽卡／興建（可跳過）

## B. 村莊建築（自由放置）
- [ ] 「放」可揀未建建築，點空地放置；Esc／右鍵取消
- [ ] 幽靈預覽：綠可放／紅不可（疊建築、出界）
- [ ] 升級成本隨等級上升（客棧 Lv1→Lv3→更高明顯變貴）
- [ ] 客棧／醫館／練功場生效：飽食、療傷、閒置 XP

## C. 出征循環
- [ ] 亂山坡倒數約 **14 秒**；毒沼約 **20 秒**（懸賞榜 Lv.2）
- [ ] 剔選俠客出征 → 短自動戰鬥（亂山＝hills／毒沼＝mire 底圖）→ 回村收銀／毛皮（／鐵）；結算文案有拾獲筆記／受傷提示
- [ ] 秘境用 crypt、前哨用 outpost 戰鬥底圖
- [ ] 失敗時收益縮水、可能額外受傷
- [ ] 自動再出征（同時最多約 2 隊）可開關
- [ ] 離線／讀檔後到期出征會結算

## D. 俠客列表／稀有
- [ ] 頭像有**稀有色邊**（白→綠→藍→紫→橙→紅）

- [ ] 橙 128／紅 256 縮到列表尺寸唔爆框
- [ ] 若偶發無圖色塊：清楚顯示**兵種短標＋稀有**
